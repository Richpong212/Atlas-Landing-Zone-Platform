# Atlas Landing Zone Platform

This project builds a production-style AWS platform from the ground up using a landing zone approach.

The goal is to learn and demonstrate:

- AWS multi-account architecture
- Landing zone design
- Environment separation
- Security guardrails
- Centralized logging
- EKS platform engineering
- CI/CD
- Observability
- Incident response
- Multi-region scaling
- Disaster recovery

## Project Phases

1. Landing Zone Foundation
2. AWS Organizations and Account Structure
3. Security and Logging Foundation
4. Guardrails and Governance
5. Network Foundation
6. Dev EKS Cluster
7. First Workload Deployment
8. CI/CD Pipeline
9. Staging and Production Accounts
10. Observability
11. Reliability and Incident Response
12. Multi-Region Scaling
13. Disaster Recovery
14. Platform Runbooks
15. Interview Stories
